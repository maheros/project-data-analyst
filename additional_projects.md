## ADDITIONAL DATA ANALYSIS PROJECTS

**Customer Behavior Analysis for Retail Security**
*Tools: Python, Pandas, Matplotlib, Excel*
- Analyzed 6 months of store security footage data to identify customer traffic patterns
- Created predictive models to optimize security staff scheduling based on peak hours
- Developed visualization dashboards showing correlation between store sections and security incidents
- Reduced security response time by 35% through data-driven staff positioning

**Employee Attendance Pattern Analysis**
*Tools: SQL, Power BI, Excel*
- Designed a database system to track employee attendance across multiple security sites
- Implemented SQL queries to identify patterns in late arrivals and absences
- Created Power BI reports for management to visualize attendance trends by location and time period
- Resulted in 20% improvement in staff punctuality through targeted interventions

**Security Incident Reporting System**
*Tools: Python, SQLite, Streamlit*
- Developed a web-based application for security guards to log incidents digitally
- Implemented data validation and categorization features to ensure consistent reporting
- Created automated weekly and monthly summary reports with statistical analysis
- Reduced report processing time by 60% and improved data accuracy by 45%

**Visitor Flow Optimization for Corporate Buildings**
*Tools: Excel, Python, Tableau*
- Collected and analyzed visitor check-in/check-out data from multiple corporate buildings
- Identified bottlenecks in visitor processing during peak hours
- Created simulation models to test different check-in procedures and staffing levels
- Implemented recommendations that reduced average visitor wait time by 25%
