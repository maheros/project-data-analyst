# مشاريع تحليل البيانات

هذا المجلد يحتوي على مشاريع تحليل بيانات متنوعة تظهر مهارات ماهر نعمان باكور في مجال تحليل البيانات والذكاء الاصطناعي.

## المشاريع المتضمنة

### 1. تحليل بيانات المبيعات (Sales Data Analysis)
مشروع Python لتحليل بيانات المبيعات وإنشاء تقارير وتصورات مرئية للمساعدة في اتخاذ القرارات التجارية.

**المهارات المستخدمة:**
- Python (Pandas, Matplotlib, Seaborn)
- تحليل البيانات الإحصائي
- التصور المرئي للبيانات
- إنشاء التقارير التحليلية

### 2. لوحة معلومات Power BI لتحليل بيانات الأمن والزوار
مشروع Power BI لإنشاء لوحة معلومات تفاعلية لتحليل بيانات الأمن وحركة الزوار في المباني المؤسسية.

**المهارات المستخدمة:**
- Power BI
- تصميم لوحات المعلومات التفاعلية
- تحليل البيانات المؤسسية
- التقارير المجدولة

### 3. تحليل بيانات وسائل التواصل الاجتماعي
مشروع Python لتحليل أداء المحتوى على منصات التواصل الاجتماعي المختلفة وتحديد أفضل الاستراتيجيات.

**المهارات المستخدمة:**
- Python (Pandas, NLTK)
- تحليل المشاعر (Sentiment Analysis)
- تحليل الاتجاهات والأنماط
- تحليل المشاركة والتفاعل

## كيفية استخدام المشاريع

كل مجلد مشروع يحتوي على ملفات التعليمات البرمجية والوثائق اللازمة لتشغيل المشروع. يرجى الرجوع إلى ملف README.md داخل كل مجلد للحصول على تعليمات محددة.

## المتطلبات

- Python 3.x
- مكتبات Python: pandas, matplotlib, seaborn, nltk
- Power BI Desktop (للوحة المعلومات)
